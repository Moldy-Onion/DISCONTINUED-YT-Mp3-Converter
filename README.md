# YT-Mp3-Converter
I made a simple YouTube Mp3 Converter with Python scripting. It is just a link section with a download button and a progress bar. You can download the executable file to open and run right away or use my script to make adjuments. This converter aims to be the best and saftest application for mp3 converting, no more fishy websites with redirects to virus infested websites and no more adds just a easy to use converter. Currently it is just as easy as as copy and paste link and press download.

Making adujustments:
Start by downloading the latest version of Python from etheir www.python.org or the Microsoft Store. 
Next make a new folder in the location you want to save the project. 
Then go to www.gyan.dev/ffmpeg/builds/ and got to builds and download your platforms latest version.
Now copy paste the ffmpeg executable file into your project folder this is required for the mp3 converting because Python can't do it nativly.
Next open the terminal and type "pip install yt-dlp" this is a required extension for the YouTube implementation.
From here you can copy paste my script and make changes as you wish as I have also made sure to clearly lable in my script what each parts do.
